Что это за приложение

Oblako Messenger — приложение-клиент для сети Matrix. Сообщения хранит сервер Matrix, к которому вы подключаетесь. В тестовой версии вы можете быть подключены к публичному серверу, например matrix.org: у него своя политика конфиденциальности, и именно он хранит данные вашего аккаунта.

Что хранится на вашем устройстве

Данные входа, ключи шифрования и кэш сообщений. Удаление приложения или выход из аккаунта удаляют эти данные с устройства. Если не сохранить ключ восстановления, прочитать старые зашифрованные сообщения на новом устройстве будет нельзя.

Шифрование

Личные чаты в Matrix шифруются сквозным шифрованием: содержимое сообщений не может прочитать оператор сервера. Оператор видит технические данные, например идентификатор аккаунта, состав комнат и время отправки сообщений.

Аналитика

В приложении есть настройка аналитики. В текущей тестовой версии мы не подключали сервис аналитики, поэтому данные об использовании не отправляются нам.

What this app is

Oblako Messenger is a client app for the Matrix network. Messages are stored by the Matrix server you connect to. In the test version you may be connected to a public server such as matrix.org, which has its own privacy policy and stores your account data.

What is stored on your device

Sign-in data, encryption keys and a message cache. Uninstalling the app or signing out removes this data from the device. If you do not save a recovery key, you will not be able to read old encrypted messages on a new device.

Encryption

Private chats in Matrix use end-to-end encryption, so the server operator cannot read message contents. The operator can see technical data such as your account ID, room membership and when messages are sent.

Analytics

The app has an analytics setting. In the current test version we have not connected any analytics service, so no usage data is sent to us.
